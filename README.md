# LEBREW SMOKE 除烟机 网页版上位机

电脑本地运行的网页版上位机，通过 **蓝牙（Web Bluetooth）** 或 **串口（Web Serial）** 连接除烟机，
支持整机操作、屏幕同款状态镜像、实时曲线、设置读写与三通道固件升级。
基于通信基座 comm_link（零 npm 依赖，原生 ES Module）。

## 快速开始

    start_server.cmd        一键起服务并用 Edge/Chrome 打开 http://127.0.0.1:8767/app.html
    tests\run_tests.cmd     全部自测（协议 27 + 基座 52 + 前端 5，不需要硬件，需要 Node 18+）

- 页面默认勾选「模拟设备」：不接硬件即可完整体验全部功能（含三条 OTA 通道演练）。
- 连真机：取消勾选，点「连接蓝牙」（设备广播名 `LEBREW SMOKE`）或「连接串口」选 COM 口。
- **浏览器要求 Chrome / Edge**（Web Bluetooth / Web Serial 仅这两家支持）。

## 功能一览

- **主控**：屏幕镜像（六态状态、净化等级、切换器连接态与位置、挡位/转速/进出风口温度/催化温度/PWM/VOC/湿度/环温），
  开始/停止除烟（带设备侧状态守卫）、Boost 开关（橙/白状态对显）、12 挡位调节、气流切换器三位置（左开/双开/右开）；
  故障弹窗与横幅（与设备屏同款文案）
- **实时曲线**：进风口温度 / 出风口温度 / 电机转速 / 发热丝 PWM（固定 0-100），同一时间轴，可暂停、切时间窗、导出 CSV
- **设置**：与设备设置菜单同款（语言 / 温度单位 / Boost 时长 / 记忆功能 / 催化温度 300–330℃ 步进器），
  传感器自检，关于（软硬件版本，与设备「关于」页同源）
- **固件升级**：串口 .bin（5A A5 帧传输）/ 蓝牙（0x2A39/40 窗口 ACK 协议）/ WiFi 热点直传（设备 SoftAP，浏览器 POST）
- **日志**：双通道原始收发（HEX/文本、暂停、清空、导出）

# 通信协议完整指令表

协议与固件 `smoke_cmd.c/.h` 一一对应。除特别注明 **大端（BE）** 外，多字节整数一律**小端（LE）**。

## 通道封装

| 通道 | 承载方式 |
|---|---|
| 蓝牙 | 服务 `0x180D`。`0x2A37` Notify 上行帧；`0x2A38` Write 命令（16B 密钥 + 命令 + 参数）；`0x2A39` Write+Notify OTA 控制/ACK；`0x2A40` WriteNoResponse OTA 数据 |
| 串口 | UART0 115200-8N1。帧 = `5A A5 | len:2B LE(=payload 长度) | payload | CRC16-Modbus:2B LE`（CRC 覆盖 len+payload），与日志同口输出，按魔数同步 |
| WiFi | 设备 SoftAP（升级模式）。电脑连热点后浏览器直传 `http://192.168.4.1`，仅用于 OTA |

**命令密钥（16 字节，命令载荷前缀）**：

    A6 C3 CA 4B 9C 1C 46 B8 58 E9 4B D1 D2 A5 56 A6

## 下行命令（上位机 → 设备）

命令载荷 = `16B 密钥 + 命令字节 + 参数`（蓝牙写 0x2A38 / 串口帧 payload）。

### 运行控制

| 命令 | 编号 | 参数 | 说明与状态守卫（与实体按键一致） |
|---|---|---|---|
| 开始除烟 | `0x20` | `[挡位 0-100]`（可省略=当前挡位，>100 截到上限） | 冷却中 / 故障锁存中忽略；重复开始忽略 |
| 停止除烟 | `0x21` | 无 | **仅除烟进行中（预热/运行/Boost）受理**，进入冷却；待机/冷却/故障忽略 |
| Boost 开 | `0x22` | 无（时长用设备设置的 Boost 时长） | 预热完成后才生效 |
| Boost 关 | `0x23` | 无 | Boost 激活时生效 |
| 设置挡位 | `0x24` | `[挡位 0-100]` | Boost 中不允许调速；运行中平滑斜坡到新转速 |
| 气流切换器位置 | `0x28` | `[1 左开 / 2 双开 / 3 右开]` | 需切换器已连接；执行后推 `0xB1` 上报实际位置 |

### 设置读写

| 命令 | 编号 | 参数 | 说明 |
|---|---|---|---|
| 语言 | `0x26` | `[0 中文 / 1 English]` | 写入设备 SYS_DATA，屏端全量刷新文案 |
| 温度单位 | `0x27` | `[0 ℃ / 1 ℉]` | 屏端温度符号同步 |
| Boost 时长 | `0x2D` | `[5 / 10 / 15]` 分钟 | 仅这三档 |
| 记忆功能 | `0x2E` | `[0 关 / 1 开]` | 开=记忆上次挡位，下次开机恢复 |
| 催化温度 | `0x30` | `[温度 x0.1℃ 2B LE]` | 范围 300.0–330.0（3000–3300），步进 5℃ |
| 传感器自检 | `0x32` | 无 | 分阶段上报 `0xB4` |

### 读回与遥测

| 命令 | 编号 | 参数 | 应答 |
|---|---|---|---|
| 读全部设置 | `0x40` | 无 | `0xB0` |
| 读状态 | `0x41` | 无 | `0xB1` |
| 读传感器 | `0x42` | 无 | `0xB2` |
| 读版本 | `0x43` | 无 | `0xB3` |
| 遥测开关 | `0x50` | `[使能 0/1][周期 ms 2B LE]`（周期可省=500） | 周期性 `0xA1`，最小 100ms |
| 进热点升级 | `0x60` | 无 | 设备重启进 SoftAP 升级模式（会断开蓝牙/串口） |

### OTA 传输控制（写 0x2A39 / 串口帧）

| 包 | 格式 | 说明 |
|---|---|---|
| START | `[0x11][total:4B BE][chunk:2B BE]` | chunk ≤ 244；总长校验，成功回 ACK(ok) |
| END | `[0x12]` | 设备校验字节数、切换启动分区后重启（约 200ms 后） |
| ABORT | `[0x13]` | 中止本次传输 |
| 数据包 | `[seq:2B BE][chunk ≤244B]` | **无命令号**；串口通道按传输状态路由（升级中仅 1 字节 END/ABORT、7 字节 START 视为控制包） |

**节奏要求（本机硬件实测）**：串口帧间 ≥ 8ms、蓝牙包间 ≥ 6ms，否则丢字节/塞满设备队列；
每 10 包一个 ACK 窗口（`ACK_WINDOW=10`），窗口超时或 NACK 从其 seq 重发。
完整 2MB 固件：WiFi 约 9 秒 / 串口约 4 分半 / 蓝牙数分钟。

## 上行帧（设备 → 上位机）

### ACK（蓝牙 0x2A39 Notify / 串口帧）

    [0xA0][ok:1B 0成功/1失败][seq:2B BE]      ← 注意 ACK 的 seq 是大端

### 遥测 `0xA1`（周期推送，17B + CRC16 LE 覆盖前 17B）

| 偏移 | 字段 | 说明 |
|---|---|---|
| 0 | `A1` | |
| 1 | 设备状态 | 0 待机 1 预热中 2 运行 3 Boost 4 冷却中 5 故障 |
| 2 | 挡位 % | 0-120 |
| 3-4 | 转速 rpm | 2B LE |
| 5-6 | 进风口温度 x0.1℃ | i16 LE |
| 7-8 | 出风口温度 x0.1℃ | i16 LE（= 催化温度实测） |
| 9 | 发热丝 PWM % | 0-100 |
| 10-11 | VOC 指数 | 2B LE |
| 12 | 湿度 % | |
| 13 | 环境温度 ℃ | i8 |
| 14 | 净化等级(bit0-1) + 切换器状态(bit2-3) | 净化 0-3；切换器 0 未连接 1 搜索中 2 已连接 |
| 15-16 | 故障码 | 保留 0（故障走 `0xA2` 事件） |

### 故障事件 `0xA2`（4B + CRC16 LE）

    [A2][code:2B LE][active:1B 1激活/0恢复]

| 故障码 | 含义 |
|---|---|
| `0x01` | 进风温度异常 |
| `0x02` | 出风温度异常 |
| `0x03` | 发热丝异常 |
| `0x04` | 风扇电机异常 |
| `0x05` | 进风口 PT100 异常 |
| `0x06` | 出风口 PT100 异常 |
| `0x07` | 温度传感器自检失败 |
| `0x08` | VOC 传感器自检失败 |
| `0x09` | 湿度传感器自检失败 |
| `0x10` | 电机异常 |

### 设置读回 `0xB0`（7B）

    [B0][语言][温度单位][Boost时长min][记忆功能][催化温度 x0.1℃ 2B LE]

设置在设备端被修改（含屏上操作）时也会主动推送本帧。

### 状态读回 `0xB1`（7B）

    [B1][设备状态][挡位%][净化等级][切换器状态][Boost激活 0/1][切换器位置 1左开 2双开 3右开]

切换器位置变化（上位机下发 / 实体按键 / 从机到位确认）都会推送本帧。

### 传感器读回 `0xB2`（9B）

    [B2][进风口 x0.1℃ 2B LE][出风口 x0.1℃ 2B LE][湿度%][环温 i8][VOC 2B LE]

### 版本读回 `0xB3`（12B）

    [B3][软件版本 主.次.修 3B][硬件版本 主.次.修 3B][型号][运行秒数 4B LE]

版本唯一事实源为固件 `app_version.h`，与设备「关于」页一致。

### 自检上报 `0xB4`（5B，随 `0x32` 分阶段推送）

    [B4][阶段 0开始 1温度 2+VOC 3+湿度][温度结果][VOC结果][湿度结果]   结果：0 进行中 1 通过 2 失败

### 文本帧（ASCII，蓝牙 0x2A37 / 串口）

调试文本直通；页面识别 `AP:REBOOTING`（进热点模式）等关键字。
